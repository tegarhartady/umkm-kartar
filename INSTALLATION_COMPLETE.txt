                                    ↓

│                                                                              │
│    UMKM kunjungi: /umkm/login                                              │
│    └─ Input: Email + Password (dari admin)                                 │
│    └─ POST /umkm/login                                                     │
│    └─ System validate email & password                                     │
│    └─ Check status = DISETUJUI                                             │
│    └─ Create session (guard: umkm)                                         │
│    └─ Redirect → /umkm/dashboard                                           │

  Solution: 
    ✅ Check UMKM status = 'disetujui' di database
    ✅ Pastikan password ter-hash

  Problem: Foto tidak upload
  Solution:
    ✅ Run: php artisan storage:link
    ✅ Check: public/storage symlink ada
    ✅ Verify folder permissions

  Problem: Authorization error
  Solution:
    ✅ Register ProductPolicy di AuthServiceProvider
    ✅ Check umkm_id di products table

  Problem: Route tidak ketemu
  Solution:
    ✅ Run: php artisan route:clear
    ✅ Verify routes ada di routes/web.php
